# INTERAURA — IROS

Um terminal interativo para sessões de RPG, com estética de computador antigo, conteúdo narrativo e participação compartilhada entre jogadores.

[Abra o terminal](https://soggypoiuytr.github.io/interaura-iros/).

## Desenvolvimento

Os arquivos do site ficam em `site/`. Execute `npm test` para verificar a integridade dos arquivos e os testes do projeto. A publicação utiliza GitHub Pages.
